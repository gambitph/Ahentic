An intelligent AI agent that understands your WordPress site and works alongside you to build, edit, troubleshoot, and manage it.

== Description ==

**Ahentic** brings a Cursor-like AI workspace directly into WordPress.

Instead of simply embedding an AI chatbot, Ahentic provides an intelligent agent that understands the current WordPress site, can inspect its state, and work alongside you to build, edit, troubleshoot, and manage it.

= Features =

* AI workspace designed for WordPress
* Extensible architecture for tools and agents
* Built to grow with Ask mode, Agent mode, and WordPress abilities

More features coming soon.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ahentic` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use **Settings → Ahentic** to open the plugin settings.
