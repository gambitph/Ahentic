# Site knowledge is an interpretive brief, not a stack dump

Site knowledge (`ahentic_site_knowledge`) is a short markdown brief (purpose, visitors, voice, conventions, constraints, confirmed notes) that Ahentic infers with consent and injects into later runs.
Live WordPress inventory (plugins, theme, setup, sitemaps) is read during a dedicated study job as evidence and discarded, because it goes stale and abilities already return it.
Users edit one document with headings; Premium adds a textarea, Free runs the same pipeline.
This beats caching site state in the option, splitting knowledge into a CMS of fields, or loading it on demand like a playbook.
