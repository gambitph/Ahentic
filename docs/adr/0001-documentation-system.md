# Documentation system: PRD / contract / how-it-works

We split Ahentic docs into product PRDs (`pro__premium_only/docs/prd/`), free subsystem `CONTRACT.md` files, and colocated how-it-works maps. PRDs define should; contracts define must-guarantee interfaces; how-it-works must not invent product law. A PRD index forbids new narrative docs outside that list so private notes and free maps stop drifting into three truths.
