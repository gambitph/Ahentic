# Concept walkthroughs

Beginner-oriented, cross-stack HTML walkthroughs of **one** Ahentic concept, feature, or subsystem at a time.

Generated (or refreshed) via the **`explain-codebase-concept`** skill. See [`docs/agents/explain-concept.md`](../agents/explain-concept.md).

## Authority

These files are **pedagogical**. They are not product law.

| Kind | Wins when |
| --- | --- |
| Product PRD | Intended behavior |
| `CONTRACT.md` | Must-guarantee interface |
| Colocated how-it-works | Current machinery map |
| **This folder** | Human onboarding / wiring story only |

When a walkthrough disagrees with a PRD or contract, fix or regenerate the walkthrough — do not treat it as a fourth source of truth (ADR-0001).
